# Recruiter Project Summary

GemDuel is my strongest engineering project: a React, TypeScript, and Electron strategy-game desktop app organized as a pnpm/Turborepo monorepo. The repository separates Electron runtime code, shared game/domain logic, reusable React UI, a TURN credential service, and governance scripts into dedicated workspaces. My strongest portfolio angle is not a public launch claim; it is the engineering system around a complex local game: replay infrastructure, test coverage, desktop runtime boundaries, and tooling that makes the project easier to verify.

The project includes Replay vNext support for saving, reading, auditing, and simulating gameplay replays; UI tests for importing and re-exporting replay JSON; network replay synchronization safeguards; and Visual Lab dev tooling for reviewing board-game surface assets with ratings and comments. It also includes governance checks for architecture boundaries, Electron IPC policy, dependency/release health, and evidence artifacts. Current verification is mixed: direct workspace typechecks and several governance checks passed locally, while full test runs currently fail because lifecycle seal-exclusion reviews are overdue. This makes GemDuel useful for roles that value careful TypeScript engineering, QA automation, build/release discipline, game tooling, and evidence-based AI-assisted workflows.
